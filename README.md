# Rock Paper Scissors 🎮

A simple Rock Paper Scissors game built with Python.

## Features

- 🎯 Rock, Paper, Scissors gameplay
- 🤖 Random computer choice
- 🏆 Score tracking
- ❌ Invalid input handling
- 🚪 Quit option

## How to Play

Choose one of the following options:

1. Rock
2. Paper
3. Scissors
4. Quit

The computer will randomly choose an option, and the winner will be decided according to the game rules.
